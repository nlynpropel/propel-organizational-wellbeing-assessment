PROPEL WELL-BEING OPPORTUNITY INDEX
RECOMMENDATION BANK — PLAIN-TEXT IMPORT CONTENT

PURPOSE
This recommendation bank supports deterministic scoring, tailored client reports, broker guidance, and mapped Propel capability recommendations for the Propel Well-being Opportunity Index.

IMPLEMENTATION RULES
- Use the diagnosis, client-facing recommendation, recommended first step, and client meeting question in client-facing reports.
- Broker-only views may also display behavioral principles, psychological signals, trigger logic, recommendation group, and Propel capabilities.
- Low scored-question responses should create diagnostic-tag severity.
- Rank eligible recommendations deterministically.
- Suppress multiple selected recommendations from the same recommendation group.
- Preserve the exact wording below.
- Store this content in a versioned, immutable recommendation framework.
- Snapshot selected recommendation content and rationale when a result is finalized.
- Do not generate or rewrite recommendation text with AI.

IMPORTANT QUESTION-MAPPING RULE
Resolve each Q-number trigger against the final published Propel Well-being Opportunity Index question order. The recommendation bank was developed while the incentive-clarity question was being added. Validate every numeric trigger against the final question text before production activation; do not rely on question numbers alone when a mapped question ID or diagnostic tag can be used.

TITLE: Create a Guided Starting Experience
BANK CATEGORY: Clarity of Value
STRATEGY DIMENSION: Experience and Access
PRIMARY DRIVER: Clarity of Value
SECONDARY DRIVER: Structural and Environmental Friction
RECOMMENDATION GROUP: Onboarding
PRIMARY TRIGGERS: Q13 score 1-3; client selects employees do not know where to begin; Q14 score 1-2
DIAGNOSIS: Employees may be aware that resources exist but lack a clear entry point or next action.
